# Focus Overlay — Windows focus cards

Focus Overlay — локальное Windows-приложение, которое показывает небольшие карточки поверх рабочих окон. Пользователь оставляет перед глазами текущую задачу, заметку или изображение и одной клавишей переключает карточки между режимами редактирования и невмешательства.

## Цель MVP

Проверить основной сценарий: несколько полезных карточек постоянно видны, не мешают работе в других приложениях, восстанавливаются после перезапуска и управляются без открытия тяжёлого рабочего пространства.

MVP предназначен для Windows 10/11 и работает полностью локально. Карточки не синхронизируются с облаком и не требуют учётной записи.

## Основной сценарий

1. Пользователь запускает приложение и видит компактный controller.
2. Через controller или global hotkey создаёт Task, Note либо Image.
3. В Edit mode перемещает, изменяет размер и редактирует карточки.
4. Включает «Не мешать»: служебные controls исчезают, карточки остаются видимыми, а клики проходят в приложения под ними.
5. Возвращается в Edit mode глобальной клавишей.
6. После перезапуска приложение восстанавливает карточки, содержимое и расположение.

## Режимы

### Edit mode

Карточки интерактивны. Синяя точка в controller обозначает доступное управление. При наведении служебные символы плавно проявляются поверх карточки, не сдвигая заголовок и содержание. Окно можно перемещать и изменять его размер. В спокойном состоянии остаются только цветной маркер типа, заголовок и содержание на светлой бумажной поверхности.

### Focus mode

В интерфейсе этот режим называется «Не мешать». Карточки остаются видимыми и сохраняют контур, но не получают события мыши, поэтому пользователь продолжает работать в расположенных под ними приложениях. Янтарная точка в controller обозначает click-through mode, а символ действия меняется с `⊘` на `↩`. Расшифровка режима доступна по кнопке `?`. Вернуться в Edit mode также можно global hotkey или через tray.

## Типы карточек

- **Task** (`✓`, фиолетовый) — короткий заголовок, необязательное описание и флаг выполнения.
- **Note** (`✎`, зелёный) — заголовок и многострочный текст.
- **Image** (`▧`, оранжевый) — локальное reference-изображение. Кликните по области изображения и нажмите `Ctrl+V`, либо перетащите один image file из Explorer или изображение из браузера. Bitmap и browser image копируются в локальное хранилище приложения; для локальных файлов сохраняется ссылка на оригинал. В обычном режиме видны заголовок и `Uniform` preview. При наведении кнопка `⛶` включает `UniformToFill`: изображение доходит до скруглённых границ карточки, а заголовок и маркер скрываются. Кнопка `↙` возвращает обычный вид.

Если файл Image был перемещён или удалён, карточка должна оставаться управляемой и показывать понятный placeholder.

## Связи между карточками

В Edit mode наведите мышь на карточку и потяните синюю точку `●` к другой карточке. Во время жеста отображается гибкая пунктирная линия, а карточка-цель подсвечивается. После отпускания связь пружинит к цели, показывает подсказку `Связь создана · ⌁ настроить` и остаётся видимой при перемещении или изменении размеров карточек. Тонкая цветная линия, белый полупрозрачный halo и небольшой наконечник сохраняют читаемость поверх любых рабочих окон.

Символ `⌁` включает Relation Lens выбранной карточки: её связи, цветные порты и подписи показываются полностью, а остальные линии приглушаются до 30%. Закреплённый рядом инспектор размером около 270 × 210 px позволяет выбрать одну из нескольких связей, ввести подпись, выбрать одну из пяти цветовых точек, переключить направление `—` / `→` / `←` / `↔` или удалить связь через меню `•••`. Нажмите `Esc` или `×`, чтобы закрыть Relation Lens. Линии пропускают клики и остаются видимыми в режиме «Не мешать».

## Горячие клавиши

- `Ctrl+Shift+F` — переключить Edit/Focus mode.
- `Ctrl+Shift+Space` — создать карточку из clipboard:
  - bitmap или один локальный image file → Image;
  - текст → Note;
  - пустой или неподдерживаемый clipboard → открыть controller без создания карточки.

Конфликт регистрации hotkey не должен аварийно завершать приложение. Controller показывает предупреждение и оставляет соответствующее действие доступным через UI.

## Границы MVP

В MVP не входят timer, несколько workspaces, синхронизация, аккаунты, интеграции, произвольный OLE drop неизвестных типов (поддерживаются image payload из Explorer и браузеров), snap layouts, autostart, updater, installer, analytics и полноценная система тем.

- [x] FOC-009 Сделать интерфейс цельным и убрать задержки взаимодействия
  Controller и карточки должны выглядеть как единый современный минималистичный Windows-инструмент: компактный content-first layout, единая типографика, мягкие скругления, нормальные размеры hit targets и отсутствие стандартного устаревшего chrome. Controller не должен превращаться в dashboard из вложенных панелей. Карточки используют светлую бумажную поверхность с высоким контрастом текста; пользовательская настройка opacity в MVP не нужна. В спокойном состоянии карточка показывает прежде всего содержание; drag, delete и другие служебные controls появляются при наведении только в Edit mode. Приложение не должно создавать второй controller при запуске. Ввод текста, перемещение и resize не должны инициировать неконтролируемый поток параллельных SQLite writes; сохранение должно выполняться с debounce и гарантированным flush при выходе. Повторный запуск приложения не должен создавать ещё один независимый набор окон.

  **Implemented:**
  - Controller сокращён до одной строки режима, трёх действий и краткой hotkey-подсказки.
  - Карточки переведены на светлую бумажную поверхность с контрастным текстом и hover-only chrome.
  - Пользовательский opacity control удалён; карточки отображаются со 100% opacity.
  - Действие «Фокус» переименовано в понятное «Не мешать» / «Вернуть управление»; карточки сохраняют видимый контур в click-through mode.
  - Удалён дублирующий запуск controller через `StartupUri`; добавлена single-instance mutex.
  - Text, geometry и resize writes объединяются 420-мс debounce, SQLite writes сериализованы, а выход выполняет flush.
  - SQLite переведён в WAL/NORMAL с busy timeout; добавлен concurrent-write regression test.
  - Визуально проверены controller, карточка с читаемым текстом и Release build.

- [x] FOC-012 Поддержать перетаскивание изображений из браузера
  Image-карточка должна принимать не только `FileDrop` из Explorer, но и типичные browser drag payload: bitmap, `text/uri-list`, Chromium/Windows URL formats, Firefox URL formats и HTML fragment с `<img src>`. При drag-over распознаваемого изображения курсор показывает Copy и карточка включает тот же оранжевый drop cue вместо красного запрета. Bitmap и `data:image/...` сохраняются локально; публичный `http/https` image URL скачивается без cookies и авторизационных данных в `%LOCALAPPDATA%\FocusOverlay\images`. Загрузка ограничена 25 MB и 15 секундами, требует успешного image decode и не должна заменять текущий preview при HTTP, MIME, size или decode error. Обычная ссылка на web page не считается изображением, если payload не содержит image-specific bitmap или `<img src>`. Во время загрузки карточка показывает короткий статус. После успешного drop локальный path и preview сохраняются так же, как при `Ctrl+V`.

  **Implemented:**
  - Распознаются WPF bitmap, `text/uri-list`, Firefox URL formats, `UniformResourceLocator(W)`, plain URL fallback и HTML fragment с `<img src>`.
  - Browser bitmap и `data:image` сохраняются локально; `http/https` image загружается без cookies и проверяется через WPF decoder.
  - Добавлены timeout 15 секунд, лимит 25 MB, MIME allowlist и удаление повреждённого частичного файла.
  - Обычная ссылка на страницу без image-specific payload отклоняется и не заменяет текущий preview.
  - Drag-over выполняет только распознавание формата без сетевого запроса и показывает Copy/drop cue для допустимого payload.
  - Добавлены три browser image tests; полный набор проходит `6/6`.
  - Self-contained `win-x64` publish завершён успешно.

Отпускание над другой карточкой создаёт связь с короткой пружинной анимацией «пуньк», а отпускание в пустом месте или над исходной карточкой отменяет жест. Постоянная связь рисуется плавной кривой между ближайшими гранями окон, автоматически перестраивается при перемещении и resize карточек и остаётся видимой в режиме «Не мешать». Отдельный прозрачный слой связей всегда пропускает клики и не перекрывает приложения. Для связи хранятся исходная и целевая карточки, необязательная подпись, один из пяти спокойных цветов и направление: без стрелки, вперёд, назад или в обе стороны. Символ `⌁` открывает компактный редактор связей выбранной карточки, где можно изменить подпись, цвет и направление либо удалить связь. Повторная связь между той же парой карточек не создаётся, а открывает существующую. Связи сохраняются в SQLite, восстанавливаются при запуске и удаляются вместе с любой из связанных карточек. Анимация кратковременна и не должна держать постоянный rendering loop.
