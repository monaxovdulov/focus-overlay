Реализуй MVP проекта Focus Overlay полностью за один проход.

Сначала прочитай `AGENTS.md` и все перечисленные в нём документы. Спецификация в `docs/prd/focus-overlay.md` является источником истины. Не расширяй MVP и не останавливайся после scaffolding: доведи вертикальный сценарий до работающего Windows-приложения.

Требуемый результат:

- WPF-приложение на C#/.NET 10;
- создание Task, Note и Image карточек;
- каждая карточка является отдельным frameless always-on-top окном;
- карточки перемещаются, меняют размер, opacity, редактируются и удаляются;
- глобальные hotkeys создают карточку из clipboard и переключают Edit/Focus mode;
- Focus mode делает карточки click-through, Edit mode возвращает интерактивность;
- состояние и геометрия восстанавливаются из SQLite после перезапуска;
- есть компактный controller и tray с базовыми командами;
- решение собирается, тестируется и публикуется в Release.

Работай автономно и принимай разумные локальные решения внутри спецификации. Не проси подтверждения для обычных технических деталей. После реализации выполни все проверки из `memory-bank/06-one-shot-implementation-plan.md`, обнови PRD и memory bank фактическими результатами, затем дай краткую сводку с командами запуска и известными ограничениями.
