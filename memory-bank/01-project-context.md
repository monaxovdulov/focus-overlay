# Project Context

## Название

**Focus Overlay**

## Проблема

Во время работы важная задача, короткая заметка или reference-изображение быстро теряются среди вкладок и окон. Обычный todo-list требует переключения контекста, а полноэкранный overlay мешает взаимодействовать с приложениями под ним.

## Идея

Показывать несколько небольших карточек поверх любых обычных Windows-окон. Каждая карточка является самостоятельным native window. В Edit mode карточки можно менять; в Focus mode они становятся click-through и работают как ненавязчивый визуальный слой.

## Основной пользователь

Один локальный пользователь Windows 10/11, который работает в редакторе, браузере, документах или созвонах и хочет держать перед глазами только текущий фокус.

## Jobs to be done

- Быстро вынести текст из clipboard поверх текущей работы.
- Закрепить одну задачу, не открывая отдельный task manager.
- Держать reference image рядом с редактором.
- Временно сделать все карточки неинтерактивными одной клавишей.
- Вернуть прежний layout после перезапуска.

## Метрика успеха прототипа

Пользователь может за минуту создать три карточки, разложить их на двух мониторах, перейти в Focus mode, продолжить работать через них и после перезапуска получить тот же layout.

## Не-цели первого прохода

- Коммерческий релиз и polished onboarding.
- Полный kanban или project management.
- Cross-platform support.
- Cloud/backend/account.
- Плагины и внешние интеграции.
- Большой прозрачный canvas на весь монитор.
- Десятки разновидностей карточек.
